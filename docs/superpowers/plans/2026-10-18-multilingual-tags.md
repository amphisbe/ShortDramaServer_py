# 多语言标签实施计划

**目标：** 落实本轮已确认的英文编码、多语言翻译、短剧标签权重和个人兴趣管理。

**架构：** `tags` 是稳定编码字典，`tag_translations` 与 `tag_aliases` 管理展示和旧数据映射。短剧保存编码权重 JSON，个人画像按用户和标签编码唯一存储；旧接口继续返回原有展示字段。沿用 FastAPI、Peewee、MySQL/SQLite 和现有管理员鉴权。

本轮确认的方案优先于较早的 tag-module-multilang-design.md；暂不引入其标签合并、UGC 和搜索热度模型。观看心跳、推荐评分及客户端不属于本次标签模块。
