# 随机 For You 实施计划

按用户本轮要求，第一阶段采用随机抽取视频，替代原设计中的个性化评分和固定批次；原算法保留为后续设计。

- [x] 隔离测试：默认五条、鉴权、批内去重、语言与上架过滤、真实地址、当前用户互动状态、少量和空候选。
- [x] 新增独立 GET /api/v1/for-you，count 默认 5、范围 1～20，content_lang 默认 en。JWT 确定用户，禁止通过请求指定其他用户状态。
- [x] 在已上架且地址非空的分集中使用 MySQL RAND / SQLite RANDOM 抽取；不要求标签和时长，不创建统计行。
- [x] 复用播放项格式，补 dramaId、isFavorited，保留播放器兼容字段，返回 data.list。各请求独立抽取，无游标，跨请求可重复。
- [x] 同步方案并完成回归：37 项通过、1 项可选 MySQL 临时库测试跳过。不修改客户端和数据库结构。
